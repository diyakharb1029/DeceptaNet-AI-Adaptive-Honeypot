# DeceptaNet – AI-Driven Adaptive Honeypot Framework

DeceptaNet is a next-generation cybersecurity deception framework that leverages Artificial Intelligence, Machine Learning, and Reinforcement Learning to dynamically engage, deceive, and analyze cyber attackers in real time.

Unlike traditional static honeypots, DeceptaNet adapts its behavior based on attacker actions, escalates interaction intelligently, and generates actionable threat intelligence mapped to the MITRE ATT&CK framework.

This project was developed as part of a Major Academic Project in Cyber Security & Forensics.
